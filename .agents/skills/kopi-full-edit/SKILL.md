Read AGENTS.md, docs/ASSISTANT.md, docs/WORKFLOWS.md and docs/VERIFICATION.md.
Resolve `node kopi.mjs profile show --workflow full-edit` before planning. Add a
show only when the user or brief explicitly selects it. Load no Shorts preferences.
Current instructions override profile defaults; proposals follow docs/PROPOSALS.md.

Use the installed engine's edit-video skill and relevant creative skills. A short
source recording can still be a full edit. Preserve complete intended speech and
distinct CTAs unless a shorter edit was requested. Select graphics, effects,
opening/end cards and sound only from this workflow's profile/brief and available
assets. Missing assets are not permission to generate, purchase or fetch replacements.

Use local transcription and one source/output timing map. Protect approved caption
wording and accepted edits through revisions. Verify exact opening frames, encoded
transitions and speech boundaries, report limitations and retain prior outputs.
No cloud jobs, publishing or unrelated automation are enabled by this skill.
