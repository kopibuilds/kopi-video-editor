# Generic repurposing style options

Offer these as starting directions during setup, or use the user's own reference.
They are independent of any client or show and do not carry logos, handles,
colours, footage or private template assets. They are layout descriptions for
local authoring, not an installed library of fully implemented templates.
Do not choose a style without checking existing preferences and the current brief.

## Shorts

| Option | Layout |
| --- | --- |
| Speaker focus | Portrait crop following the active speaker, with readable phrase captions clear of the face. |
| Stacked conversation | Two source views stacked vertically when the footage supports them, with captions in a safe central area. |
| Speaker plus visual | Speaker footage paired with a relevant supplied visual or source detail; preserve context. |

Propose 1080 × 1920 (9:16) if no format is specified; keep source-compatible frame
rate. Confirm caption styling, crop and optional branding. Natural speaking
expressions remain part of moving video. Missing second views or supporting
assets are not permission to fabricate them.

## Carousel

| Option | Layout |
| --- | --- |
| Photo and statement | One selected source frame per slide with a clear headline and short supporting text. |
| Stacked dialogue | Two source-frame panels per slide with accurate dialogue and a progressive question/answer sequence. |
| Text-led cards | Strong headline, short takeaway and optional small portrait, with more emphasis on reading than photography. |

Discuss square 1080 × 1080 or portrait 1080 × 1350; use the brief's actual format.
Confirm slide count and copy before laying out. Quotations and summaries must
remain distinguishable. Select flattering still frames under IMAGE-EDITOR.md.

## Poster

| Option | Layout |
| --- | --- |
| Single-frame quote | One strong source frame with a concise quote or takeaway and optional attribution. |
| Three-panel dialogue | Three horizontal source-frame panels on one portrait canvas, with readable dialogue text. |
| Takeaway poster | One headline, a few key points and an optional source portrait or image panel. |

Discuss 1080 × 1350 or another requested size. A poster is one composition, not
a carousel squeezed onto one page. Keep text readable and clear of faces.

## Branding and editing

Use only user-approved palettes, handles and supplied logos. A handle, logo,
watermark or show title is optional; none is implied by an option above.
Static layouts must retain separate editable text and replaceable photos and
an export button as documented in IMAGE-EDITOR.md. Reuse the existing generator;
if a selected composition requires unsupported layering, identify that limitation
and adapt or extend it locally before claiming the design is editable.
