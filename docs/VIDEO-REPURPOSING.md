# Video to carousel, poster or Shorts

Use this workflow for a local video or a YouTube video link repurposed into a
carousel, poster or Shorts. It is one entry point, not one shared design preset.
Produce only the requested outputs; a link alone does not authorize all three.
If the output is unclear, ask which is wanted. Ordinary full-video edits still
use kopi-full-edit. Topic-only graphics are outside this source-video workflow.

## First use and saved designs

Before production, follow REPURPOSE-SETUP.md when the requested output lacks
confirmed settings. Reuse existing profiles/preferences first. Ask about optional
handle/logo, colours, format and design only where missing; offer the independent
generic directions in REPURPOSE-STYLES.md or accept a supplied reference. Save
answers/assets locally under ignored preferences/repurpose/, separated by
brand/project and output. Never reset existing preferences or copy private
branding into public examples. Set up only the requested outputs.

## Source and content

Read YOUTUBE.md before downloading a public YouTube source with node kopi.mjs
download URL. Reuse existing local media and matching transcripts. Inspect actual
source material and use node kopi.mjs transcribe when needed. Preserve supplied
corrections and distinguish verified dialogue from uncertain transcription. Keep
source ranges and attribution with the private project. Proposals follow
PROPOSALS.md; do not produce final outputs while proposal approval is pending.

## Keep output preferences separate

- Shorts: use kopi-shorts, WORKFLOWS.md and the selected shorts profile. Preserve
  its framing, caption, audio and verification rules. Do not inherit static layouts.
- Video carousel: use its confirmed local setup or selected private carousel
  references and current brief. Do not load Shorts styling as a static-design preset.
- Video poster: use its confirmed local setup or selected private poster
  references and current brief; do not silently
  turn the carousel layout into a poster or copy the Shorts layout.

Read preferences/rules.md for applicable later corrections. Load only relevant
sections. Private profile selection is stored locally as documented in PROFILES.md.
If the selected package includes references/photo-carousel.md, read that file and
only the reference images for the requested output from the selected installation.
Do not assume every package has that filename or invent a new profile CLI mode.
The current profile tool supports full-edit and shorts, not carousel/poster.
If a selected static reference cannot be resolved, report that limitation. For
users without a private pack, run REPURPOSE-SETUP.md and save their own design
choices rather than substituting another output's preferences.

A separately supplied graphics pack is an optional style source, not a replacement
for the saved video-carousel/poster references. Use its templates only when the
user or current brief selects them. Do not publish private instructions or assets.

## Static output production

For newly written carousel/poster copy, establish topic, audience and format from
the brief, asking only for missing essentials. Present slide/panel copy and caption
for approval before layout. Supplied final copy or an already approved source plan
need not be approved again. Summaries must preserve meaning; do not label a
paraphrase as a verbatim quotation. Use verified source facts and identify sources
for additional statistics.

Follow IMAGE-EDITOR.md for layered static designs, flattering source-frame
selection and checking the actual crop. A still need not match the exact spoken
timestamp; keep person, attribution and context accurate. This does not authorize
cuts around normal speaking expressions in moving Shorts.

Build only the requested carousel/poster with separate replaceable photos and
editable text. Check layout, readability, face clearance and primary editing/export
interactions. Deliver the HTML editor with PNG export as the only default graphic
output; separate PNG/JPG files require an explicit request. Provide the accompanying
caption and useful alt text. Preserve prior work under inbox/outbox conventions.

No unattended batches, publishing, external paid execution or credential access
is enabled by this workflow.
