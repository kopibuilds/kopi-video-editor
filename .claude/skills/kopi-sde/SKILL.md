# SDE / Event Highlights

Read AGENTS.md, docs/ASSISTANT.md, docs/EVENT-HIGHLIGHTS.md and
docs/VERIFICATION.md. Reuse Kopi's local media, composition and render tools.
This is an assistant workflow, not a new downloader, watcher or cloud service.

Start from the event name, provided details and actual media. Ask about missing
must-include moments/people, tone, optional logos/branding, background music,
text and deadline. Follow up on important unanswered choices; allow none,
you-choose and defer where appropriate. Do not assume unmentioned branding/music
is approved or require the user to prepare extra creative assets.

Default to vertical 1080x1920 without repeatedly asking for aspect-ratio approval.
Use 90 seconds as a proposed starting target; inspect the footage and recommend
shorter or up to roughly two minutes when the story supports it. Explicit length,
aspect ratio, reference or current brief wins. Do not pad to hit a duration.

Load only applicable event preferences, keeping them separate from Full-edit,
Shorts and graphics-pack settings. Save confirmed recurring event choices under
ignored preferences/events/; keep one-off event details in the private project.
Preserve existing private instructions and unrelated settings.

Inspect/list/download only supplied sources using available authorized access.
Public Drive access must actually work; do not invent file IDs or silently use
saved credentials, sign in, or change sharing. Report incomplete inventories.

Propose a coherent event sequence, select useful footage/photos, and build with
the existing local engine. Proposal-only requests stop before authoring/rendering;
a direct create request permits local production once essential choices are clear.
Keep source media intact and retain a source-to-output map and editable project.

Inspect the encoded result, including opening, crops, transitions, text and audio
boundaries. State any listening/inspection limits honestly. Deliver an MP4 and
editable project location, not a static HTML editor as the video deliverable.
No account connection, paid generation, upload, publishing or ongoing folder
monitoring is enabled by this skill.
