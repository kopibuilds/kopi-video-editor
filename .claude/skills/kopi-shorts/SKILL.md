name: kopi-shorts
description: Select passages from a long-form source and create or revise Shorts/Reels using Kopi, with a separate Shorts profile. Includes proposal-only passage selection when requested.
---

Read AGENTS.md, docs/ASSISTANT.md, docs/WORKFLOWS.md and docs/VERIFICATION.md.
Resolve `node kopi.mjs profile show --workflow shorts` before planning. A show
preset is optional and explicit. Never load full-edit styling as Shorts defaults.

For a YouTube source, read docs/YOUTUBE.md, reuse existing yt-dlp and download one
source into inbox. Do not use browser credentials or launch an unrequested batch.
Inspect the source and local transcript to select coherent passages. If asked
for options, show timestamps, accurate content and reasons before editing; follow
docs/PROPOSALS.md. Do not treat a rough automatic transcript as verified dialogue.

Use the installed engine's short-form-edit skill with the selected Shorts profile
and current brief overriding house-style defaults. Preserve the passage's meaning
and complete payoff. Full-edit effects, sound reactions, chapter tabs, music and
end cards are not automatically inherited. Caption clean-up must preserve meaning;
once wording is approved, keep it through visual revisions and retime it yourself.

Frame actual source shots, including the first source camera cut and reactions.
Verify frame zero, every frame of the first second, moving subjects, caption
layout changes and encoded joins. Do not infer speaker turns from camera presence.
Keep audio and video on the same timing map; document listening limits honestly.
No Drive upload, scheduling, cloud workers or publishing is enabled automatically.
