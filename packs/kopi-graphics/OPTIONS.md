# Layout and appearance options

These are generic layouts. None contains a brand palette, client assets, account
identity or photo source. Platform-inspired appearances are visual suggestions,
not platform integration, exact replicas or evidence of an actual published post.

| Family | Options |
| --- | --- |
| Social card (tweet) | Neutral, X-inspired, Threads-inspired or LinkedIn-inspired; optional identity/subtitle; optional decorative interaction symbols. No invented counts or verification badges. |
| Photo panel | User-selected panel/text colours, 35–100% opacity, border colour, square/rounded corners, panel width and placement. |
| Quote card | Floating card placement/width, light/dark/custom theme, optional avatar/identity and emphasis. |
| Blurred social card | The same four social appearances over a blurred local photo; light/dark/custom card. |
| Highlighted quote | User-selected highlight/text colours, placement, optional user-supplied signature/logo. |
| Infographic | Stats, pictograms, steps, nested levels, two-column comparisons, timelines and checklists. |

Social-card appearance, colour theme and background are independent. For example,
a Threads-inspired dark card may sit over a blurred photo. Background choices are
plain, solid, photo or blurred. Light/dark adjust text, muted details, surfaces and
borders together. Custom themes require all documented palette fields and visual
contrast checking. Use settings colours, not an unrelated private brand palette.

System fonts are Arial, Verdana, Georgia, Trebuchet MS or Tahoma. A reference can
guide further local customization; this release does not bundle font files or
promise identical font rendering across operating systems.

Carousels can mix coordinated cover/content/closing families. Compose them as
different slides in one spec, keeping the same identity/theme unless the brief
requests a change. Slide numbers/swipe cues may be included as approved text;
there is no automatic platform navigation embedded in exported images.

Shorts presets stay in Kopi's video-repurposing workflow. These static templates
are not new moving-video compositions or a replacement Shorts style.
